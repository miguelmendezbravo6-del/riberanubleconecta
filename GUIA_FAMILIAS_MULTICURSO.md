# Uso para familias con varios estudiantes

1. Administración crea o completa los niveles Prekínder (NT1), Kínder (NT2) y 1.º a 8.º básico.
2. Registra a cada estudiante en su curso, incluso si dos hermanos están en la misma sección.
3. Crea **una sola cuenta** para el apoderado y vincula esa cuenta con cada estudiante mediante Gestión → Vincular apoderado o Vinculación masiva.
4. El apoderado inicia sesión y abre **Inicio → Mis estudiantes**. Verá cada estudiante y los cursos correspondientes.
5. En el mismo inicio consulta los avisos pendientes por curso y las próximas actividades; el botón «Ver curso y actividades» abre la vista correspondiente.
6. Las vinculaciones se administran exclusivamente por personal autorizado. Nunca se debe vincular un estudiante por coincidencia de apellido sin comprobar la relación.

**Privacidad:** un apoderado no puede ver el panel familiar de otra cuenta; el servidor filtra siempre por el usuario autenticado. Para usar datos reales deben completarse las validaciones de producción, seguridad y autorización institucional.
